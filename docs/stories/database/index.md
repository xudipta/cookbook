# The Card Catalogue

A story that teaches databases with a library. Three short chapters: the librarian who reads every book (what an
index is and why every one costs something), reading the map (query plans, the order of columns in an index, and
one query that runs forty times) and renovating without closing (safe migrations: test on staging, add before you
use, stop using before you remove). Play it on a phone: every step is a tap.

<div id="story" data-story="database">
  <noscript>This story needs JavaScript.</noscript>
</div>

This story runs on the same simulated database as the practice game, so the plans, timings and errors are real. To
write the SQL yourself, play [Index Fund](../../games/database/index.md), or read the
[database notes](../../../topics/database/README.md).
