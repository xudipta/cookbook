# The Switchboard

A story that teaches MCP with a switchboard. Three short chapters: first plugs (what an MCP server is, and the two
ways to plug one in: a local program or a hosted service), who may call and the door code (scopes, secrets kept off
the file, and tools versus resources versus prompts) and a stranger on the line (why a new server must be read before
it is approved). Play it on a phone: every step is a tap.

<div id="story" data-story="mcp">
  <noscript>This story needs JavaScript.</noscript>
</div>

This story runs on the same simulated host as the practice game, so the commands and their output are real, and a
wrong choice is replayed to show what it would really do. To type the commands yourself, play
[Patch Bay](../../games/mcp/index.md), or read the [MCP notes](../../../topics/mcp/README.md).
