# The Night Superintendent

A story that teaches Linux troubleshooting with a building at night. Three short chapters: a first night of
three pages (a permission, a busy process, a full disk), the front desk (a service that keeps restarting, a
flood of errors, a port nobody can reach) and a bad Friday (a backup that lies, a process that ignores a polite
kill, a full disk with a trap). Play it on a phone: every step is a tap.

This story runs on the same simulated server as the practice game, so every command and its output is real. To
type the commands yourself, play [Night Shift](../../games/linux/index.md), or read the
[Linux notes](../../../topics/linux/README.md).
