# The New Hire

A story that teaches Agent Skills with an assistant who has a small desk and a binder of recipe cards. Four short
chapters: a small desk (what goes on the title, in the card and in the appendix), the title on the card (a
description that triggers when it should), ship it (the lint gate, where a skill lives and which tools it may
use) and skill or something else (a skill, a hook, an MCP server or a subagent). Play it on a phone: every step
is a tap.

<div id="story" data-story="skills">
  <noscript>This story needs JavaScript.</noscript>
</div>

This story runs on the same simulator as the practice game, so the desk sizes, the agent's picks and the lint
report are real. The agent here is a deliberately simple stand-in that counts matching words; a real model reads
more cleverly. To write the skill yourself, play [Skill Issue](../../games/skills/index.md), or read the
[skills notes](../../../topics/skills/README.md).
