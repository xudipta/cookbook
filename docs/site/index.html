How a story teaches

First the picture. Then the word.

  1. A place you already know

    A kitchen, a library, a switchboard. The topic is dressed as something familiar, so you are not decoding jargon and the idea at once.

  2. You do one thing

    Tap a cook to send them home. Add a cook. Flip a switch. Then watch what happens, and guess before you see it.

  3. Now the real name

    A card maps each kitchen word to the real one, with the real command. You end with a notebook and links to the notes.

Practice

Then practise with the real commands.

One game per topic, ten live. Each models a real tool closely enough that the commands transfer: a cluster fails, a build crawls, a state file drifts.
