How a game teaches

            
The loss is a pointer to the page you needed.

          

          
    
            
  1. An incident arrives
    A pod crash-loops, a layer cache misses, a CI job leaves a lock behind. The board shows the symptom, not the cause.

  2. You diagnose and fix it
    Use a real prompt: kubectl describe, docker build, terraform plan. Reading is free; changes cost a move.

    Each resolved incident links to the exact note section behind it, so you can read the theory after you have felt the problem.
